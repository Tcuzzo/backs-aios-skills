# BACKS AIOS 0.9.6

## Model-agnostic skill policy

Build Flow and the Clean Code Gauntlet explicitly allow the same capable model,
provider or family in separate authoring and review executions. Required review
independence comes from fresh context without the author's conversation. A model
label does not prove independence or decide eligibility.

Model Fusion compares independent candidate executions when the task benefits
from a panel or the operator requests one. One configured model can fill all
roles in separate executions. Removed the different-model preference and the
automatic trigger for any substantial build. Existing shared budgets, regression
evidence and review isolation remain in place.

All six locale mirrors carry the same clarification. Claude and Cursor manifest
descriptions and the visual guide now describe independent review consistently.
Blind Eval's introduction identifies the reviewing execution, removing ambiguous
wording that could be read as excluding the author's model identity.
No executable provider adapter or native dispatcher was changed by this skill
policy update; separate runtime configuration remains subject to its actual
capabilities and restrictions.
