# BACKS AIOS 0.9.8

## The blind-spot bridge reaches the public pack

`turn-and-burn` now carries the blind-spot evidence contract in the public pack,
not only inside the private platform. The public body ships the six rules in short
form and links a new reference file:

- `skills/turn-and-burn/references/blindspot_protocol.md` — the full contract,
  the evidence record, the verdict function, and the acceptance scenarios that
  pass and the ones that fail.
- `skills/turn-and-burn/SKILL.md` — the portable body, with the six rules and a
  plain list of what the pack cannot do for you.
- The six locale mirrors (`de`, `es`, `fr`, `hi`, `pt-BR`, `zh-CN`) carry the same
  contract, translated, and point at the canonical protocol.

The rules that now travel with the pack:

1. A +1 needs every required predicate, with current evidence.
2. Admission, execution and observation stay three different facts.
3. A builder cannot author its own authoritative positive verification.
4. Independent review runs on frozen inputs, in separate scratch, and isolation
   is claimed only when the runtime enforces it.
5. Repeated confidence without new evidence triggers one decisive probe.
6. The host's own organs are used, and anything the host cannot enforce stays
   marked unvalidated until demonstrated.

## The contract cannot pass itself

Two soft passes shipped in the first draft of the public protocol, and both are
closed here:

- The evidence record had no way to say "observed" — the kinds were `test`,
  `command`, `file`, `receipt` and `review` — so the branch that requires an
  observation could never be taken. The record now carries an explicit
  `observed` boolean, and that branch reads that field.
- The verdict function never looked at the status, so a mechanism still marked
  `unvalidated until demonstrated` could carry a +1. The function now takes the
  status and returns -1, naming the undemonstrated mechanism, before any pass.

The four locale mirrors that carried a word from another language, or a
misspelling that hid the right word, were corrected and reviewed. Two guards now
keep both classes closed: one reads the protocol and checks its shape, one reads
every mirror and checks the language it is written in.

## The README says what is not there

Two new sections set expectations before the reader buys the dream:

- **What this pack does not include** — no running platform, no cross-session
  memory, no model router or budget ledger, no proof engine, no enforced
  reviewer isolation, no agent coordination, and no live-surface proof.
- **What you bring to get the same behavior** — the six organs that turn the
  discipline from a suggestion into a floor: a gate, a red test you run, a real
  side effect to assert, a way to start a fresh session, a lessons file, and a
  bounded loop with a checkpoint.
