# BACKS AIOS 0.9.9

## Highlights

- Ships the canonical `blind-spot` skill across Claude Code, Codex, and Cursor plugin stores.
- Bundles stdlib-only deterministic scripts under `skills/blind-spot/scripts/`:
  - `signed_gate.py`: strict `-1 / +1` integer binary predicate gate (no truthiness traps, no verdict multiplication, fail-closed on missing/stale/unauthored evidence).
  - `observable_probe.py`: deterministic subprocess probe emitting signed `-1 / +1` SHA-256 receipts.
  - `blind_packet.py`: allowlisted scratch packet freeze, symlink/escape-hardened manifest verification, and outside-read/input-write isolation canaries.
- Includes all 6 locale mirror stubs (`de`, `es`, `fr`, `hi`, `pt-BR`, `zh-CN`) with full locale integrity.
