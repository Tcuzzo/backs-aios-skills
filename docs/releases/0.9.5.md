# BACKS AIOS 0.9.5

## Context that leads to execution

`backs-build-flow` coordinates the existing disciplines with one integration owner,
task mode, current context packet, pinned base/candidate revisions, remaining mission
allowance, and requested finish. Optimus's existing JavaScript and Python loaders
deliver the actual Build Flow body alongside Optimus and human-calibration and bind
receipts to the bytes delivered. Missing bodies produce diagnostics without denying
tools or claiming successful loading.

Absorb owns capability adoption. REA returns discovery or verification evidence to
its caller, avoiding a recursive Absorb/REA lifecycle. Repairs, reviews, workers and
handoffs inherit the same remaining allowance. A budget stop checkpoints unresolved
work; it cannot reset the budget, weaken acceptance, or manufacture PROVEN.

## Inline quality and complete candidate scope

The loop preserves real RED, the sealed original test, the minimal complete fix,
repository lint/type/behavior checks, the clean-code gauntlet, independent review,
and requested delivery. Supplemental test files cover later findings without
rewriting the original contract. Checks record actual commands, results, revisions,
and justified unavailable or inapplicable tools.

Sniper Testing includes a read-only Git scope helper. It compares the verified
pre-task base with the current candidate, then optionally reports staged, unstaged
and untracked work separately. Committing a fix no longer makes its test scope
disappear. Invalid revisions fail explicitly; unusual filenames remain intact.

## Operator awareness without a hardcoded persona

`operator-essence` owns one private, evidence-backed awareness file. It preserves
confirmed preferences, qualitative observations, quantitative populations and
denominators, uncertainty, counterexamples and context-specific adaptations.
Missing or stale context triggers one supported insights assessment or a clearly
reported supplied-evidence fallback. Sparse context remains provisional while
useful authorized work continues.

The helper validates one explicit private document and can bootstrap a missing
empty file without overwriting existing content. It does not run an insights model,
crawl history, execute profile text, or infer operator identity. The public package
contains only the reusable method, validator and format.

Intent compilation interprets the current request once. Intent deduction resolves
remaining choices inside that directive. Human calibration reuses the same essence
evidence instead of starting a second questionnaire or profile cycle. Current
instructions, project facts and actual authorization remain authoritative.

## Distribution

All six locale mirrors and eight plays carry the same integration. Compatibility
aliases remain byte-identical in source and loose installs. The Claude archive and
managed Codex bundle omit alias folders from canonical discovery.

The Codex refresh now includes its own playbooks, propagates an explicitly selected
home to the child installer, and rejects linked package roots. It preserves unrelated
catalog entries and managed-instruction boundaries. It does not rewrite arbitrary
Claude JSON or Codex TOML settings. Running desktop sessions still need a fresh
session or the host's reload procedure before they can discover new content.

## Verification record

The regression work uses real host subprocesses, temporary Git repositories and
isolated installation directories. Test fixtures contain no real operator profile.

- Initial baseline: 313 tests passed, 10 skipped, 3291 subtests passed.
- Build Flow/scope RED: 14 expected failing behavior assertions before implementation.
- Essence RED: 16 expected failures before the helper existed.
- Codex packaging/home RED: 9 failures reproduced before the fixes.
- A supplemental date regression reproduced a future-start/unknown-end validation
  defect before its fix; the original sealed tests stayed unchanged.
- Focused integrated verification: 59 passed, 1 skipped, 8 subtests passed.
- New helper lint and shipped JavaScript/shell syntax checks passed.
- Corrected whole-pack run: 387 passed, 11 skipped, 3942 subtests passed.
- Final one-line loader simplification: 38 focused checks and 6 subtests passed;
  its independent review confirmed equivalence and approved the code candidate.
- Real translated-install and packaged-alias regressions reproduced both review
  findings before their fixes; an independent rerun passed all 32 consumer checks.
- Eight selected controlled faults were detected in a bounded disposable-checkout
  mutation campaign. This is scoped evidence, not an exhaustive mutation score.

Final whole-pack, committed archive, independent-review and remote-delivery receipts
are recorded in the integration plan. Local tests do not establish installation on
an operator's separate desktop, a successful unsupported host command, or measured
production improvement.
