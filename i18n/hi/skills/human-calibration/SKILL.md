# अपने Human को समझें

Operator के वर्तमान अनुरोध और corrections अपनाएँ। उनकी working preferences के evidence
से उपयोगी explanations, progress updates और design tradeoffs चुनें। Awareness बदल सकने
वाला context है; स्थायी persona या permission नहीं।

## Profile की एक pass

[operator-essence](../operator-essence/SKILL.md) private awareness file और उसके
 evidence का owner है। [Build Flow](../backs-build-flow/SKILL.md) से उसका current slice
दोबारा उपयोग करें। वह गायब हो तो उस skill का उपलब्ध insight workflow एक बार चलाएँ,
supplied report/history का आकलन करें और कम evidence में provisional awareness बनाएँ।
हर downstream skill से insight collection फिर शुरू न करें।

Operator द्वारा निर्दिष्ट मौजूदा profile evidence दे सकता है: essence में reconcile करते
समय source, date, confirmation status और uncertainty बचाएँ। असंबंधित profiles न खंगालें,
display name से file के व्यक्ति का अनुमान न लगाएँ। Personal information public plugin
source से बाहर रखें। Read-only task profile लिखे बिना in-memory slice दे सकता है।

## ज्ञात context लागू करें

- स्पष्ट current preferences और corrections historical observations से ऊपर हैं।
  Project facts और acceptance checks फिर भी सत्यापित करने होंगे।
- Observed choices और inferred tendencies अलग रखें। अस्वीकृत design या बार-बार माँगे
  progress updates किसी खास adaptation का आधार हैं; वे personality, identity,
  competence या general risk tolerance नहीं सिद्ध करते।
- सबसे छोटा संबंधित slice लें: preference या observation, supporting evidence,
  proposed adaptation और uncertainty। Operator को उसका source दिखाएँ।
- किसी वास्तविक tension, जैसे context depth और execution speed, के दोनों पक्ष बचाएँ।
  ठोस readiness condition और evidence से उसे सुलझाएँ; goal छोटा करके नहीं।
- Taste या communication का महत्वपूर्ण unknown optional question से सुलझ सकता है।
  पहले उपयोगी अधिकृत काम करें। Questionnaire अनिवार्य न बनाएँ और केवल नया session होने
  के कारण पहले से दी गई preferences फिर confirm न कराएँ।
- Profile लिखना अधिकृत हो तो corrections और counterexamples दर्ज करें। Correction
  awareness बदलता है; task को चुपचाप नहीं बदलता और unrelated actions का अधिकार नहीं देता।

## Output

Existing task owner को संक्षिप्त awareness slice लौटाएँ। User उसे देख और सुधार सकता है।
Agent की communication और evidence gathering अनुकूल करें; सभी operators के लिए factual,
quality और authorization standards समान रखें।
