# Die aktuelle Anfrage übersetzen

Übersetze die Worte des Operators in einen ausführbaren Vertrag, benenne die
Lesart kurz und arbeite weiter. Verdichteter Ausdruck kann eine vollständige
Spezifikation enthalten. Der Operator muss daraus kein Engineering-Ticket machen.

## Eine Auslegung für die aktuelle Aufgabe

Enthält das aktuelle Paket bereits eine Direktive und ändert keine neue Anweisung
sie, verwende sie weiter. Dieser Skill besitzt die Sprachinterpretation;
[operator-intent-deduction](../operator-intent-deduction/SKILL.md) besitzt eine offene
Entscheidung innerhalb dieser Direktive. Keiner startet den gesamten Ablauf des anderen neu.

### 1. Die tatsächlichen Worte auslegen

Extrahiere gewünschte Fähigkeit, Handlung, benannte Flächen, Mengen, Einschränkungen
und beobachtbaren Abschluss. Markiere ungeklärte Verweise und Metaphern.
Wiederholung kann Nachdruck sein, ohne eine zweite Aufgabe zu erzeugen. Ton kann
Dringlichkeit ausdrücken; er begründet keine Erlaubnis, Risikotoleranz, Kompetenz oder Identität.

Deute bildhafte Sprache im tatsächlichen Aufgabenkontext. „Reiß es ab“ kann einen
Ansatz meinen; das allein autorisiert keine Datenlöschung. Antworte klar, ohne
Dialekt nachzuahmen oder eine Persona zu erfinden.

### 2. Nur handlungsrelevante Unsicherheiten klären

Nutze innerhalb der maßgeblichen Anweisungen diese Reihenfolge:

1. Aktuelle ausdrückliche Anfrage und Korrekturen des Operators.
2. Bereits festgelegter Umfang und Autorisierung in diesem Gespräch.
3. Verifizierte Projektfakten, Ziele, Verträge und aktueller Zustand.
4. Relevante bestätigte Präferenzen und belegte Beobachtungen aus
   [operator-essence](../operator-essence/SKILL.md).
5. Klar gekennzeichnete vorläufige Schlussfolgerung bei dünner Beleglage.

Fehlt Essence oder ist sie veraltet, führt ihr Verantwortlicher den einen
unterstützten Insights-Durchgang aus und gibt einen vorläufigen oder aktuellen
Ausschnitt zurück. Verschachtelte Skills verwenden ihn weiter, statt erneut
Verlauf zu sammeln. Historische Präferenzen überstimmen keine neue Anweisung.
Quellfakten können den Weg begrenzen, ohne das Ziel zu verkleinern.

Qualitative Belege bestimmen Bedeutung und Kontext einer Präferenz. Quantitative
Belege beschreiben wiederholte Ergebnisse in ihrer angegebenen Grundgesamtheit.
Zählwerte allein entscheiden nicht, was der Operator meinte; eine im Bericht
abgeleitete Tendenz ist keine vom Operator bestätigte Anweisung.

### 3. Die Direktive erstellen

Führe diese Felder im vorhandenen Aufgabenpaket, ohne einen zweiten Plan anzulegen:

| Feld | Erforderlicher Inhalt |
| --- | --- |
| Beabsichtigte Fähigkeit | Was der Operator geschaffen oder gelernt haben möchte. |
| Aktuelle Grenze | Was verifizierter Zustand und verfügbare Fähigkeiten heute erlauben. |
| Weg jetzt | Nächste nützliche Handlung unter bestehender Autorisierung. |
| Weg später | Verbleibende Voraussetzungen für die vollständige beabsichtigte Fähigkeit. |
| Aufgabenvertrag | Modus, Ziel, Grenzen, gewünschter Abschluss und Abnahmebelege. |
| Unsicherheit | Tragende Unbekannte und Belege, die sie klären könnten. |

Halte die ganze beabsichtigte Fähigkeit sichtbar, wenn eine externe Abhängigkeit
den aktuellen Weg begrenzt. Ein Review liefert Befunde; es wird nicht still zur Reparatur.

## Lesart benennen, dann handeln

Wenn Auslegung eine Rolle spielt, nutze einen einfachen Satz:

> Lesart: Bestehende Integration aktualisieren, öffentliche Schnittstelle bewahren und vor Freigabe den tatsächlichen Verbraucher prüfen.

Kennzeichne bei Bedarf eine dünn belegte Schlussfolgerung. Führe durch Belege
gerechtfertigte reversible Arbeit aus. Kläre Faktenunsicherheit durch Inspektion
oder gezielten Versuch. Eine fehlende tragende Autorisierung oder tatsächlich
ungeklärte Operatorentscheidung bekommt nach verfügbarer Vorbereitung eine
konkrete Empfehlung und Frage; siehe [decision-bar](../decision-bar/SKILL.md).
Eine alte Präferenz ersetzt keine fehlende Erlaubnis für eine neue folgenreiche Handlung.

Gib die Direktive an [Build Flow](../backs-build-flow/SKILL.md) zurück. Nutze
Absichtsableitung nur für eine tatsächlich verbleibende Entscheidung. Spätere
Korrekturen aktualisieren vorhandenes Paket und relevante Essence-Belege; sie
ersetzen nicht still das Ziel und setzen das Missionsrestbudget nicht zurück.
