# Session Handoff
**Effort:** free — 上下文死掉之前写一份平铺文件；零模型调用，还让下个会话一开局就直接省下成本。消除：新 agent 重新推导状态、把已付过学费的坑再付一遍，以及随死去的上下文窗口一起丢失的决定。

上下文窗口会结束，工作必须延续。会话结束或压缩前准备一份新智能体可直接读懂的
交接：在做什么、工作位置、未完成内容和确切下一步。构建交接必须在上下文结束后
仍可用。使用现有 [BACKS Build Flow](../backs-build-flow/SKILL.md) 任务记录；
本技能移交该任务，不另建负责人、上下文梳理或任务。

## 什么时候写

- 上下文窗口压缩或清空之前。
- 会话结束、工作还没收尾时。
- 刚落地一件大事之后（趁热记下 commit id）。
- 一个真正的决定递到你的人面前的那一刻（记下每个选项各意味着什么）。

## 写到哪

一个下一位 agent**最先**会看的固定地方。下一位 agent 和你共享项目，就用仓库里一个稳定的台账文件，并把更新 commit 掉，让它扛得住机器重启，而不只是上下文清空。下一位 agent 是另一个运行环境或一次全新登录，就往临时目录写一份平铺的可携带文件——它是脚手架，不是要跟踪的产物。

遵守 `task_mode` 与任务写权限。只读或冻结评审在回复或已获授权的外部记录中返回
交接，绝不为了满足本技能而向受保护仓库写账本。

## 先核实并发工作（一个字都别急着写）

先确认**其他**会话的工作已被保全。跑 `git status`、`git log`、`git worktree list`。把脏文件和未合并的分支如实记进文档。绝不为了让交接显得干净而变更另一个会话未提交的工作——那正是数据丢失缺陷。另一个会话还有工作在飞，交接文档却描述一片干净，这是虚假声明。

## 写什么 — 每项一小节

1. **目标。** 一句话说明工作，下一位智能体不应猜测完成标准。携带 `mission_id`、
   `task_mode`、集成负责人、所要求完成状态和已授权交付行动。
2. **状态。** 已落地（提交 ID）、在建、排队。规格、计划、问题和差异用路径或 URL
   引用，不重复内容。包含固定 `base_sha`、当前 `candidate_sha`、封存 RED 路径/
   提交/哈希、检查命令/结果，以及每份回执对应的确切候选版本。
3. **工作住在哪。** 分支、worktree、脏文件。点名下一位 agent 必须最先读的确切文件。
4. **裁决轨迹。** 每一块是谁或什么评的、真正抓到了什么。带具名缺陷的失败裁决比一个绿更值钱——把缺陷逐字写下。
5. **半成品和下一条确切命令。** 什么在半途，以及接着跑的字面命令。
6. **待定决策。** 还在等你的人的事项，以及每个选项意味着什么。一个决定绝不能只活在一个死掉的上下文窗口里。
7. **未兑现的契约。** 还红着的测试、还缺的证明、许了还没还的承诺。
8. **坑。** 每个一行。你已经付过学费的坑比一个绿更值钱——写下来，让下一个会话不用再付一遍。
9. **建议技能。** 说明下一位智能体先加载哪些技能及理由。指出已可用的实际正文/
   证据、需刷新的内容和 operator essence 来源，不复制第二份档案。
10. **剩余预算。** 携带 [bounded-loops](../bounded-loops/SKILL.md) 中原始截止时间、
    总计/已用/剩余尝试数、轮次及其他限制，以及待完成调用和最后的假设/失败。
    未知仍标未知。交接、压缩、替换工作者或切换模型均不得重置任务预算。

## 硬性规则

- **脱敏。** 不放 API key、密码、令牌、个人数据。不放真实主机名、内网 IP、家目录路径——只用占位符；真实值用环境变量名指过去。交接文档是最可能离开这台机器的文件；经它泄露的密钥本身就是 bug。
- **"不存在"类的说法烂得最快。** 写下"X 不存在"或"X 没落地"之前，在当前 commit 上重新核实——你写的时候，并行工作正在落地。
- **每项状态有证据支持。** 能力交付只有在必需评审和真实界面证明齐全时才用
  PROVEN；否则用 STILL-BUILDING 说明缺失证据。已完成评审或本地补丁可以满足
  所请求的完成状态，不必重命名为已部署能力。
- **保持两分钟能读完**（约 120 行）。超了就把最旧的块挪进历史小节归档——绝不靠删除。

## 接手（另一半）

从交接文档启动的会话**最先**读它，然后在动手之前，把最上面的两三条声明对照 `git log` 和实况目录树验证一遍。交接是地图，不是真相——信它告诉你**去哪看**；核实它**说了什么**。

续接相同任务包和剩余额度。派发前重新检查截止时间；新会话不等于新预算。
额度耗尽时保留 STILL-BUILDING 检查点，只继续不消耗该额度的有用已授权工作。
保留原始 RED 封条和固定基线；只有实际字节改变才更新候选身份。
