# Repair Loop
**Effort:** light — 循环本身是纪律加一轮独立评审；它串起的更重步骤（闯关、陪审团）各带各的标记，且只对要出厂的改动开火。消除：“绿了但坏着”的落地，以及 bug 重开带来的返工。

任何修复、关单或升级的默认循环。它是一种行为，不是审批机器：给人加的关卡为零、摩擦为零。它约束的是 agent，用一套纪律让"绿了但坏着"在结构上就难以出厂。

## 加入当前任务

用 [BACKS Build Flow](../backs-build-flow/SKILL.md) 维持任务包、operator essence
和一位集成负责人。复用调用方已建立的适用规则、上下文、技能正文与证据，只刷新
变化内容。直接调用时仅建立一次缺失上下文。底线和必需理解关卡尚未载入时再加载；
只有路径未决才用 wayfinder。不要因修复发现而重启外层构建战术。

[bounded-loops](../bounded-loops/SKILL.md) 负责共享截止时间和剩余尝试/轮次额度。
在复现、编辑、工具、模型、评审与交接中保留 `mission_id`、`task_mode`、固定
`base_sha` 和当前 `candidate_sha`。嵌套调用不重置预算。评审和诊断模式返回证据，
不编辑或晋级；构建行动需有相应任务范围。

## 循环

1. **查明受影响路径。** 检查规则、项目当前源码、调用方契约和现有检查。
   复用当前相关证据，不重复整个仓库审计。
2. **在实况真相上复现。** 亲眼看到失败，在人真正使用的那条路径上——不是代理探针，也不是听信 bug 报告的一面之词。复现不了，就没有修复。
3. **红色契约测试。** 写一条捕捉这个缺陷的失败测试，修复之前先 commit。证明它真的是红的。修复让它变绿；修复绝不编辑测试。见 [red-first](../red-first/SKILL.md)。
4. **在接缝处修掉整类** — 而不是一个症状一块补丁。完整公式在 [seam-engineering](../seam-engineering/SKILL.md)。
5. **运行限定范围检查。** 用 [sniper-testing](../sniper-testing/SKILL.md) 从固定
   `base_sha` 到 `candidate_sha` 的汇总差异及自有待提交路径推导范围。运行仓库
   实际 lint、类型和测试命令，记录命令、结果和版本。不适用检查标为 **N/A**
   并说明原因；缺少必需工具属于缺口。不任意安装工具或编造通过。封存测试逐字节不变。
6. **在当前流程中度量。** 运行 [clean-code-gauntlet](../clean-code-gauntlet/SKILL.md)
   获取候选质量和有界变异证据。调查幸存变异体；暴露测试缺口则另加补充文件，
   保留原始 RED。修复负责行为的接缝，并在同一剩余预算内重跑受影响检查，
   不为 GREEN 弱化关卡。
7. **独立评分。** 一位没写这次改动的评分者——按能力与可用性从配置好的梯级矩阵里在线挑出；构建候选的作者执行被取消资格，任何继承了构建者对话或上下文的会话同样被取消资格；评审者必须在全新且与作者无关的会话中工作并给出通过结论。构建者绝不给自己的活打分。见 [blind-tribunal](../blind-tribunal/SKILL.md)。
8. **检查并发工作。** 变更共享状态之前，核实其他会话的进行中工作已被保全（在某个分支或 commit 上）。绝不 commit 或清理不属于你的工作。
9. **在范围内验证并落地。** 落地时完整运行一次受影响模块测试集及项目必需检查，
   再遵循已授权交付流程。验证用户实际界面或命令上的行为，记录确切候选/安装版本。
   本地测试和上游静态证据不能证明线上交付。关闭该接缝暴露的每个发现，或逐项
   记录有证据的明确“不是缺陷”裁定。“修大的、其余延后”不能落地。

## 在任务预算内迭代

失败检查产生下一个有界假设。仅在剩余额度内重试或选择有能力的配置路径；换模型
不会创建新任务。遵守 bounded-loops 的停滞与耗尽规则。达到限制时，用
**STILL-BUILDING** 建立检查点，保留当前候选、封存测试、失败证据、未过关卡和
确切下一步。继续不消耗已尽额度的有用已授权工作。未决发现阻止落地，但不会抹去
进度，也不能变成编造的 **PROVEN**。

## 硬性规则 — 任何一条都会让这个技能失败

- 没在实况真相上复现就发出的修复。
- 修完才写的测试，或被修复改过的测试。
- 补了症状，而那一类还在接缝处敞着。
- 靠代理探针宣称绿了，而人自己的路径还坏着。
- 构建者给自己的改动打了分。
- 落地时无声搁置了某个已浮出的发现。
- 重置循环、无声放弃，或未过关卡却报告绿色。

## 汇报

两个词——**PROVEN** 或 **STILL-BUILDING**——外加用大白话说清意图，以及摆在人面前的那个唯一决定（如果有）。只有品味、愿景或破坏性风险的问题才去找人；见 [decision-bar](../decision-bar/SKILL.md)。
